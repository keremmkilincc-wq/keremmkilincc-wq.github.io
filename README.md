## 🛠️ Teknoloji

- **Statik:** HTML5, Tailwind CDN, Vanilla JS (Canvas 2D), `localStorage`
- **API:** GitHub REST, FormSubmit AJAX
- **Deploy:** GitHub Pages (`main` branch)
